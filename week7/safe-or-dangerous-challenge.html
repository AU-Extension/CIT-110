Safe or dangerous? AI-suggested commands

An AI assistant can write a command in seconds, but it cannot see your computer and it does not suffer the consequences. For each request below, judge the AI's suggestion before anyone runs it, find the risky part, and choose a safer version.

How to use this challenge
  1. Read what the user asked for and the command the AI suggested.
  2. Decide: safe (run it), risky (the idea is right but it needs a change first), or dangerous (never run it).
  3. If it is not safe, point to the part of the command that causes the problem, then pick the safer version.
  4. Each command is worth 10 points: 4 for the verdict, 3 for the problem part, and 3 for the safer version. A safe command earns all 10 points for a correct verdict.
  5. Your score appears at the end with a short list of rules to remember in your own lab.

Rules for running AI-suggested commands

  1. Take a VM snapshot before you run anything that deletes, formats, or changes settings.
  2. Read every part of the command. Check every path and drive letter twice, including spaces.
  3. Preview first: -WhatIf in PowerShell, rm -i or ls with the same path in Bash.
  4. Never pipe a script from an unknown website into a shell. Use the official package manager.
  5. Use the smallest permission that works: no sudo or administrator unless it is needed, never 777.
  6. Do not switch off a security feature to fix an annoyance. Find a narrow fix instead.
