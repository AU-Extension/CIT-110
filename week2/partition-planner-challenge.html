Partition and file system planner

Before you install an operating system, you decide how the disk is divided and formatted. Choose the right file system and partition style for real situations, then lay out the disk the way Windows 11 does.

How to use this interactive
  1. Part 1: choose the best file system for eight situations.
  2. Part 2: choose MBR or GPT for four disks.
  3. Part 3: arrange the four Windows 11 partitions in order and pick the file system of each.
  4. Use the quick reference on the right if you get stuck. Every answer shows an explanation.

Quick reference

File systemGood to know
FAT32Works almost everywhere. Largest single file is 4 GB. Used for the EFI System Partition.
exFATRead and write on Windows and macOS. Very large files. No permissions or journaling.
NTFSWindows default. Permissions, encryption (BitLocker), journaling. macOS reads it but cannot write by default.
ext4Linux default. Permissions and journaling. Windows cannot read it without extra tools.
APFSApple default for macOS. Windows cannot read it without extra tools.

Partition styles: MBR supports disks up to 2 TB and 4 primary partitions. GPT supports much larger disks and up to 128 partitions in Windows, and is required for UEFI booting of Windows 11.
