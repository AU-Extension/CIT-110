Boot sequence animator

Follow a computer from the power button to the desktop, with Windows 11 and Ubuntu side by side. Then break the boot on purpose to see where each common problem appears, what the screen shows, and the first fix to try.

How to use this interactive
  1. Press Next step (or Play) to move through the boot process one stage at a time.
  2. Compare the Windows 11 and Ubuntu columns: the first steps are identical, then each OS uses its own boot loader and services.
  3. Choose a problem under Break something and play the boot again to see where it stops and what to do.
  4. Finish with the ordering exercise at the bottom.
