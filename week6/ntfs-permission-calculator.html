NTFS and share permission calculator

A Doral accounting office keeps client files in one shared folder. Set the NTFS permissions and the share permissions, choose a user, and see exactly what that user can do, both at the PC and over the network.

How to use this interactive
  1. Load one of the preset scenarios, or build your own permission entries.
  2. Pick a user on the right. You can change which groups the user belongs to.
  3. Read the effective access sitting at the PC (NTFS only) and over the network (share and NTFS together).
  4. Read the steps under each result to see which rule decided it, then change one entry and predict the new result before you look.
