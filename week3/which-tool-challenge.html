Which tool would you open?

You are working the help desk for small businesses around Miami. For each ticket, choose the Windows 11 tool that solves the problem, then the command you would type in the Run box. Twelve tickets, two points each.

How to use this interactive
  1. Read the user's complaint on the ticket.
  2. Choose the Windows tool you would open. You get feedback right away.
  3. Choose the command you would type after pressing Win + R to open that tool.
  4. Read the explanation, then move to the next ticket. Your score out of 100 appears at the end, with a review of every ticket.
  5. Not sure? Interactive 3A, the Windows admin tools map, describes every tool used here.
