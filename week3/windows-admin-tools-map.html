Windows admin tools map

Windows 11 has a tool for almost every support job: drivers, disks, slow computers, error logs, users, and background services. Explore what each tool does, three ways to open it, and what its window looks like before you use it in your virtual machine.

How to use this interactive
  1. Pick a job at the top (Hardware, Storage, Performance...) or search for a word such as driver or slow.
  2. Click a tool card to read what it is for, how to open it, and what to try in your Windows 11 VM.
  3. Practice the Run box: type a command such as devmgmt.msc and press OK, exactly as you would after pressing Win + R.
  4. Use the Win + X menu panel to see which tools are one right-click away.
  5. Try to explore all 16 tools. A green dot marks the ones you have opened.
