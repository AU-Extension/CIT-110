Process and memory visualizer

Open and close apps on a virtual machine with 2 CPU cores and 4 GB of RAM. Watch the operating system share CPU time between processes, fill up RAM, and start using the disk as extra memory when RAM runs out.

How to use this interactive
  1. Choose Windows 11 or Ubuntu. The process names and the monitoring tool change to match.
  2. Click apps to open them, and click again to close them. Watch the CPU cores and the RAM bar.
  3. Keep opening apps until RAM is full and data starts moving to the page file (Windows) or swap (Ubuntu).
  4. Start the runaway script, then find it at the top of Task Manager or top, just as you will in Assignment 5.1.
  5. Complete the four tasks in the checklist.
Operating system:

CPU: two cores sharing time

Each core runs one process at a time for a tiny slice of time (a few milliseconds), then the scheduler switches to the next process in the ready queue. It happens so fast that everything looks like it runs at once.
