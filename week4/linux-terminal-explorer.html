Linux terminal explorer

Learn how Ubuntu organizes its files, then practice real bash commands in a safe pretend terminal. Navigate folders, create and copy files, and complete a mission for a Miami print shop before you try the same commands in your Ubuntu VM.

How to use this interactive
  1. Click folders in the Linux folder tree to learn what each one holds. The button under the description runs cd and ls there for you.
  2. Click inside the black terminal and type commands, then press Enter. Type help to see what this terminal understands.
  3. Use Tab to complete file and folder names and the Up arrow to repeat earlier commands, just like in Ubuntu.
  4. Complete the 12-step print shop mission. Each step turns green when the terminal sees the right result.
  5. Watch the live view of your home folder change as you work. Reset any time; nothing here can break.

The Linux folder tree

Linux has one tree that starts at / (root). There are no drive letters like C:. Click a folder to learn what lives there.
