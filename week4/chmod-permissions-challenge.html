File permissions (chmod) challenge

Every file in Linux says who can read it, change it, and run it. Read real ls -l lines, convert between letters and numbers, pick the right chmod command, and learn to spot the dangerous shortcut that AI tools and forums sometimes suggest.

How to use this interactive
  1. Use the cheat sheet on the right whenever you need it. It is allowed.
  2. Answer 17 questions in four parts: reading ls -l, converting, choosing commands, and spotting danger.
  3. For conversion questions, type the number (like 755) or the nine letters (like rwxr-xr-x) and press Check.
  4. Read every explanation, especially when you miss one.
  5. At the end you get a score out of 100, a review, and a practice calculator to keep experimenting.

    Cheat sheet

    An ls -l line starts with 10 characters: the type (- file, d directory, l link), then three groups of three.

    -rwxr-xr-- 1 maria sales 120 Oct 20 09:15 tool.sh
    GroupWhoIn the example
    u userthe owner (maria)rwx
    g groupmembers of salesr-x
    o otherseveryone elser--
    LetterNumberOn a fileOn a directory
    r4read itlist names inside
    w2change itcreate, delete, rename inside
    x1run it as a programenter it with cd

    Add the numbers in each group: rwx = 4+2+1 = 7, r-x = 5, r-- = 4. So rwxr-xr-- is 754.

    Symbolic changes: chmod u+x file adds run for the owner, chmod go-w file removes write for group and others, chmod 640 file sets everything at once.
